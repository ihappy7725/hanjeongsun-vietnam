## 실행

Node.js 20 이상에서 프로젝트 루트 터미널을 엽니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 실행 의존성은 없으므로 테스트가 필요 없다면 설치 없이 `node scripts/serve.mjs`만으로 실행할 수 있습니다. Windows PowerShell의 npm.ps1 실행 정책 문제를 피하도록 `npm.cmd`를 사용합니다.

```powershell
npm.cmd run check
npm.cmd run build
node scripts/serve.mjs --dist
```

`dist/`에 정적 배포 파일을 생성합니다. Netlify, Cloudflare Pages 등 정적 호스팅에서 빌드 명령 `npm run build`, 출력 폴더 `dist`를 사용하면 됩니다. 서버와 API 키, 사용자 데이터 저장소는 필요 없습니다. 로컬 서버는 Ctrl+C로 종료합니다. 파일을 직접 더블클릭하면 모듈·지도 로딩이 제한될 수 있으므로 HTTP 서버를 사용하세요.

## 검증 범위와 남은 사항

저널 썸네일 5장은 글별로 새로 생성한 전용 이미지를 사용합니다. `assets/journal/`에 WebP, `assets/journal/source/`에 PNG 원본, `JOURNAL_THUMBNAIL_PROMPTS.md`에 생성 프롬프트를 보관합니다. 컬렉션은 한국 8종·베트남 5종과 한지 포장 + 단면 제품 컷으로 재구성했습니다. 이미지를 다시 준비할 필요는 없으며 상세 내용은 `COLLECTION_IMPLEMENTATION.md`에 있습니다. 데이터는 `collection-data.js`, 스타일은 `collection.css`, 웹 이미지는 `assets/collection/`, 생성 프롬프트는 `COLLECTION_IMAGE_PROMPTS.md`에서 관리합니다.

`npm.cmd run check`는 세 언어 문구, 제품 전환, 5개 저널의 링크·본문·언어 전환, 삭제 항목, 두 장의 패키지 구성, 매장·지역 선택, 모션 보간·사선 진행, 메뉴·인트로, 로컬 에셋 경로와 지도 데이터를 확인합니다. DOM 환경의 검증이며 실제 브라우저 레이아웃·이미지 크롭·애니메이션·접근성 트리 검증을 대체하지 않습니다.

컬렉션은 별도 임시 프로필의 headless Chrome에서 1440px·768px·390px, 세 언어, 두 카테고리의 126개 화면 배치 검사를 통과했습니다. 모션 감소 설정으로 촬영한 한국어 화면 6장은 `artifacts/collection-*.png`에 있습니다. 로컬 서버 실행 후 `node scripts/check-collection-browser.mjs`로 재검사할 수 있습니다(Windows의 설치된 Chrome 사용). 전체 사이트의 스크롤 모션과 실제 기기 터치·접근성 검수는 별도로 남아 있습니다. 베트남어 문구는 실제 공개 전 원어민 감수를 권장합니다. 컬렉션 제품 컷은 카탈로그 기반 생성 이미지로, 실제 촬영 원본이 생기면 교체할 수 있습니다.

로컬 HTTP 페이지와 지도 에셋은 200 응답을 확인했습니다. 비공개 Sites 프로젝트는 생성했지만, 소스 업로드·운영 배포는 자동 승인 검토에서 사용자의 명시적 배포 승인 부족으로 거부되어 진행하지 않았습니다. 따라서 현재 배포 URL은 없습니다. `.openai/hosting.json`의 기존 프로젝트 ID를 유지하고 승인 후 같은 프로젝트에 배포해야 합니다.

매장 사진과 열대과일·패키징의 자료 성격과 이력은 `ASSETS.md`에서 내부 관리합니다. 매장 주소·연락처·운영시간은 가상 정보이며 예시 전화번호에는 `XXX`가 들어가 실제 연결하지 않습니다. 사용자의 후속 요청에 따라 관련 안내는 고객용 화면에서 제거했습니다.
